# CLAUDE.md

## Operating principles

- **Be careful with tokens.** Keep responses and output concise. Don't dump full file contents when a targeted excerpt will do. Don't re-explain things already established in the conversation.
- **Code like a senior Google software engineer.** Favor clarity, correctness, and simplicity over cleverness. Write minimal, well-structured code that solves exactly the stated problem — no speculative abstractions, no unrequested features. Match existing style and conventions in this repo.
- **Always verify claims before stating them.** Don't assert that code works, a bug is fixed, or a function/file exists without checking (running it, reading the file, grepping for the symbol). If something can't be verified, say so explicitly instead of guessing.
